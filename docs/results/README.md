# Security test evidence

No scans have been run yet. Store sanitized evidence in a directory named YYYY-MM-DD-tool-version-commit.

Each run should include:
- command.txt: exact command with secrets removed
- environment.md: OS, runtime, tool version and target commit
- summary.md: findings, triage and limitations
- sanitized machine-readable output where permitted

Never commit credentials, cookies, private customer data or unredacted sensitive exploit evidence.
